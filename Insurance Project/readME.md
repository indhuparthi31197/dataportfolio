
A simple Insurance Management System built using Python, Flask, SQLAlchemy, and SQLite, demonstrating REST API design, database relationships.

This project was created as a portfolio project to practice backend development using Flask and ORM-based database access.

🚀 Features

Manage Customers, Policies, and Claims

RESTful API with proper HTTP methods:

GET – retrieve data

POST – create new records

PATCH – partially update existing records

Uses SQLAlchemy ORM

Uses SQLite as the database

Basic input validation

Demonstrates OOP principles (encapsulation via model methods)

🛠️ Tech Stack

Python

Flask

SQLAlchemy

SQLite

Postman (for API testing)
